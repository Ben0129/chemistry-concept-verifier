# 學測自然科統整複習

依 **108 課綱部定必修自然科學**（物理、化學、生物、地球科學）編寫的學測複習網站，並附**跨科統整**與**探究與實作**。先讀知識庫建立觀念，再分科刷題，最後用跨科模擬試題檢驗。純靜態網站，不需伺服器或資料庫，直接開啟 `index.html` 即可使用，也可部署到 GitHub Pages。

## 內容

| 科目 | 知識庫 | 選擇題 | 混合題組 | 題庫 |
| --- | --- | --- | --- | --- |
| 物理 | 6 單元、20 主題 | 66 | 6 | 每單元中卷 |
| 化學 | 8 單元、48 主題 | 253 | 23 | 每單元易、中、難卷（氣體單元為易、中） |
| 生物 | 5 單元、17 主題 | 55 | 5 | 每單元中卷 |
| 地球科學 | 5 單元、18 主題 | 55 | 5 | 每單元中卷 |
| 跨科統整 | 2 單元、11 主題 | 22 | 2 | 跨科中卷、探究難卷 |
| **合計** | **26 單元、114 主題** | **451** | **41** | |

每份題庫比照學測：11 題選擇題（單選＋多選）＋ 1 組混合題，滿分 100 分。多選題依學測規則計分（錯 1 個選項得 60%、錯 2 個得 20%）。每題附詳解與錯誤選項分析；混合題附參考答案與評分規準，難卷含「主張、證據、推論」論證題。所有計算題的答案與數字選項都以程式驗算過。

### 學習內容代碼

- **化學**使用 108 課綱部定必修化學的官方學習內容代碼（如 `CJa-Vc-3`），46 條全數涵蓋。
- **物理、生物、地球科學、跨科**目前使用本站依課綱主題整理的內部代碼（`PHY-xx`、`BIO-xx`、`EAR-xx`、`INT-xx`），網站上會標明「非官方代碼」。之後可對照國教院課綱原文改為官方代碼（只需修改各科的 `curriculum.json` 與題目的 `code` 欄位）。
- 各科題目可以引用其他科的代碼（例如生物的碳循環題同時標註化學代碼），答錯時可跳到兩科的相關知識點。

## 網站功能

- **知識庫**：依科目、單元閱讀，可全文搜尋；點學習內容代碼可看到該條目的所有知識點與題目。
- **刷題練習**：依科目、單元、難度、題型、未做過／錯題篩選；作答後立即顯示答案、詳解與相關知識點。
- **模擬試題**：分科單元試卷，或從所選科目隨機組成「綜合模擬卷」（題目平均分配各科，基礎／標準／挑戰三種難度，滿分 100）；計時、答案卡、交卷後自動批改選擇題，混合題對照評分規準自評。
- **錯題本**：沒有全對的題目自動加入，之後答對自動移出；也可手動收藏。
- **學習紀錄**：各科、各單元、各難度、各學習內容的正確率，自動找出弱點並可一鍵練習；可匯出／匯入紀錄。

作答紀錄只存在使用者自己的瀏覽器（localStorage）。舊版「學測化學刷題站」的紀錄會自動轉移。

## 目錄結構

```
index.html                 網站入口
assets/
  app.js                   網站程式（原生 JavaScript，無框架）
  style.css                樣式（支援深色模式、手機版）
  data.js                  由 data/ 打包產生，請勿手動修改
data/
  subjects.json            科目清單（名稱、資料夾、代表色）
  physics/  chemistry/  biology/  earth/  integrated/
    curriculum.json        該科學習內容代碼、學測不考清單、選修關鍵字
    knowledge/*.json       知識庫（每單元一檔）
    questions/*.json       題庫（每單元一檔，可含多份易／中／難卷）
tools/
  build_data.py            檢查代碼與題號並打包成 assets/data.js
  check_bank.py            檢查題庫格式、配分、難度配比、答案分布、選修概念
  smoke_test.js            以瀏覽器走過所有頁面並模擬作答每份試卷
```

## 新增或修改內容

1. 編輯 `data/<科目>/questions/*.json` 或 `knowledge/*.json`（格式見下）。
2. 檢查題庫：`python3 tools/check_bank.py`。ERROR 必須修正；WARN 逐條判斷（例如選修概念只要題幹已附規則即可保留）。
3. 重新打包：`python3 tools/build_data.py`（網站讀的是 `assets/data.js`，不執行這一步網站不會更新）。
4. （選用）瀏覽器測試：`node tools/smoke_test.js`（需要 Playwright）。

題目格式：

```json
{
  "id": "phys2-M04", "code": "PHY-05", "level": "中", "type": "單選",
  "stem": "題幹，下標寫 H_{2}O、上標寫 10^{23}",
  "options": ["A", "B", "C", "D", "E"],
  "answer": "D",
  "explain": "詳解，需說明錯誤選項的錯因",
  "table": [["表頭", "表頭"], ["資料", "資料"]]
}
```

- `type`：「單選」或「多選」；`answer` 為依序排列的大寫字母（多選如 `"ACE"`）。
- `level`：「易」「中」「難」。`id` 全站不可重複，建議以單元代號開頭。
- `code`：學習內容代碼，多個以「、」分隔，必須存在於某一科的 `curriculum.json`。
- 每份題庫的 `key` 決定配分：`E`（單選 6、多選 10、混合 10/10/10）、`M`（5、10、4/4/6/6）、`H`（5、10、4/4/12）。

新增一個單元：在該科 `knowledge/` 加一個檔（`id`、`order`、`title`、`topics`），在 `questions/` 加一個檔（`unit_id` 對應知識庫的 `id`）。新增一科：在 `data/subjects.json` 登錄並建立資料夾與 `curriculum.json`。

## 命題原則

- 以部定必修內容與國中基礎為主；選修概念只在題幹提供規則時使用（各科的 `elective_keywords` 會被檢查程式標出）。
- 計算題所需常數與原子量寫在題幹；數字選項由小到大排列。
- 錯誤選項取自常見迷思，詳解點出錯因；每份題庫的答案分布、否定問法數量由檢查程式把關。

## 部署到 GitHub Pages

Repository → Settings → Pages → Source 選擇 `main` 分支與根目錄（`/`）即可，不需建置步驟。
