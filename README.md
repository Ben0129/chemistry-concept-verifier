# 學測化學刷題站

依 **108 課綱部定必修化學** 編寫的學測複習網站：先讀知識庫建立觀念，再分單元刷題，最後用學測題型的模擬試題檢驗。純靜態網站，不需伺服器或資料庫，直接開啟 `index.html` 即可使用，也可部署到 GitHub Pages。

## 網站功能

- **知識庫**：依單元閱讀，可全文搜尋；點學習內容代碼可看到該條目的所有知識點與題目。
- **刷題練習**：依單元、難度、題型、未做過／錯題篩選，作答後立即顯示答案、詳解與相關知識點連結。
- **模擬試題**：單元試卷（易／中／難），或從所選單元隨機組成「綜合模擬卷」（基礎／標準／挑戰，滿分 100）；計時、答案卡、交卷後自動批改選擇題，混合題對照評分規準自評。
- **錯題本**：沒有全對的題目自動加入，之後答對自動移出；也可手動收藏。
- **學習紀錄**：各單元、各難度、各學習內容代碼的正確率，自動找出弱點並可一鍵練習；可匯出／匯入紀錄。

作答紀錄只存在使用者自己的瀏覽器（localStorage）。

## 目錄結構

```
index.html              網站入口
assets/
  app.js                網站程式（原生 JavaScript，無框架）
  style.css             樣式（支援深色模式、手機版）
  data.js               由 data/ 打包產生，請勿手動修改
data/
  curriculum.json       部定必修化學學習內容代碼與「學測不考」清單
  knowledge/u1–u8.json  知識庫
  questions/u1–u8.json  題庫
tools/
  build_data.py         檢查代碼並打包成 assets/data.js
  check_bank.py         檢查題庫格式、配分、難度配比、答案分布、選修概念
  smoke_test.js         以瀏覽器走過所有頁面並模擬作答
```

## 新增或修改題目

1. 編輯 `data/questions/uN.json`（格式見下）。
2. 檢查題庫：`python3 tools/check_bank.py`。ERROR 必須修正；WARN 逐條判斷（例如選修概念只要題幹已附規則即可保留）。
3. 重新打包：`python3 tools/build_data.py`。
4. （選用）瀏覽器測試：`node tools/smoke_test.js`（需要 Playwright）。

題目格式：

```json
{
  "id": "u3-M04", "code": "CJa-Vc-3", "level": "中", "type": "單選",
  "stem": "題幹，下標寫 H_{2}O、上標寫 Ca^{2+}",
  "options": ["A", "B", "C", "D", "E"],
  "answer": "B",
  "explain": "詳解，需說明錯誤選項的錯因",
  "table": [["表頭", "表頭"], ["資料", "資料"]]
}
```

- `type`：「單選」或「多選」；`answer` 為依序排列的大寫字母（多選如 `"ACE"`）。
- `code`：學習內容代碼，多個以「、」分隔，必須存在於 `curriculum.json`。
- 每份題庫的 `key` 決定配分：`E`（單選 6、多選 10、混合 10/10/10）、`M`（5、10、4/4/6/6）、`H`（5、10、4/4/12）。

## 命題原則

- 只考部定必修化學（-Vc-）與國中基礎；選修概念（如 [H^{+}][OH^{−}] ＝ 10^{−14}、原子經濟、鏡像分子、產率）只在題幹提供規則時使用。
- 不出：勒沙特列原理、平衡常數、Ka／Kb、氧化數計算、混成軌域、VSEPR、依數性質、速率定律、赫斯定律、標準還原電位、電解計量。
- 計算題所需原子量寫在題幹；所有計算題答案皆以程式驗算。
- 錯誤選項取自常見錯誤（分母誤用溶劑、濃度直接平均、忽略 CaCl_{2} 有 2 個 Cl^{−} 等），詳解點出錯因。
